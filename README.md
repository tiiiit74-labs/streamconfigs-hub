# ⚡ StreamConfigs Hub

Local-first streaming configuration manager for Stremio, Nuvio, Kodi and similar tools.

StreamConfigs Hub helps organize:
- manifests
- UUIDs
- API keys
- config URLs
- Debrid credentials
- backups & restore points

Everything runs locally in the browser.
No cloud. No account. No server required.

---

# 🇫🇷 Français

StreamConfigs Hub est un gestionnaire local de configurations streaming.

L'objectif est de centraliser facilement :
- manifests
- UUID
- clés API
- liens de configuration
- ressources Debrid
- sauvegardes/restaurations

Le projet est né d'un besoin personnel :
éviter les copier-coller permanents entre Excel, Word, notes et configs Stremio/Nuvio.

Toutes les données restent locales dans le navigateur.
